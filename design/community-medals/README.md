# 社区勋章美术

社区勋章正反面的出图提示词与处理脚本。页面使用的资产在 `src/assets/images/community/medals/`，登记规则见该目录的 README。

| 文件                 | 用途                                                                            |
| -------------------- | ------------------------------------------------------------------------------- |
| `PROMPTS.md`         | 定稿时使用的出图提示词：共用风格、等级工艺、外形规则、九枚描述与背面            |
| `cutout.py`          | 去掉近黑底得到透明底，并做边缘去色，避免浅色主题下出现黑边                      |
| `match_back_tone.py` | 背面金属色向正面外缘对齐（只改色度、保留亮度），避免翻面像换了材质              |
| `build_maps.py`      | 从透明底原图算出高度图与外轮廓，背面另算出刻字板位置                            |
| `measure_spin.py`    | 量出主创正面外圈转动的分界半径（圆周上最均匀的一圈），写回轮廓的 `spin.r`       |
| `badge.py`           | 从正面原图生成顶栏佩戴标识用的 96×96 小图（按不透明区域裁切居中，Lanczos 缩小） |
| `rebuild.sh`         | 从一组原图重新生成页面资产（去背、高度图、轮廓、WebP、顶栏小图与星盘旋转参数）  |

## 出图

1. 按 `PROMPTS.md` 用 Codex 图像生成出图。阶梯勋章先出核心档，再以核心档为参考逐档简化，保证外形与徽记一致；背面以对应正面为参考出图。
2. 出图要求正对机位、勋章约占画面 80%、近黑纯色背景、无文字。
3. 原始 PNG 不进仓库（每张约 2MB），定稿原图随 Release 附件发布，下载地址见下。改图时重出原图再运行脚本，不直接修改 WebP。

## 生成页面资产

```sh
design/community-medals/rebuild.sh <原图目录>
```

脚本输出到 `src/assets/images/community/medals/`。换图后检查背面刻字板是否被正确识别（轮廓文件中的 `dial`），以及主创正面的旋转参数（`spin`，分界半径由 `measure_spin.py` 自动量取）转动时是否看不出接缝。
