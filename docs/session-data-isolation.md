# 会话数据隔离

业务 `/api/v1/` GET 请求统一使用网络并禁止 Service Worker/浏览器缓存回退，包括图片和脚本目的类型的 API 请求。静态应用资源、字体和公开图片继续使用原有离线缓存；API 离线时返回网络失败，不展示其他会话的旧数据。新 Worker 激活时删除以前版本及当前版本的 `api-cache-*`。

认证令牌被替换、清除或用户 ID 改变时，共享弹窗立即清空。销毁前的迟到事件不再转发到业务页面；已有的旧控制器也不能更新新弹窗。

普通关闭在当前同步事件序列结束后释放实例，允许配置弹窗先关闭、再发出 `change` / `done` 完成保存和刷新。该等待期间若退出或切换账号，仍立即清空弹窗并拦截后续事件；关闭完成后的迟到事件也不转发。

卡片搜索配置、运行配置和本地媒体状态可在页面之间共用三十秒内的内存快照，最多保留 64 项，并合并同一数据的并发读取。各设置表单拿到独立副本，主动刷新仍重新请求网络；相关设置或订阅写入成功后清理对应快照，令牌变化时清理全部快照并拒绝在途旧结果。快照不写入本地存储，也不用于网络失败时的离线回退。

Agent 会话正文和历史索引以稳定用户 ID 隔离。本地旧版本使用的两个无账号键无法判断归属，因此不会迁移，升级后清除；可用的服务端历史仍通过原接口加载。退出或切换账号会清除面板内存、终止附件与消息请求、撤销录音和定时任务；迟到响应不能写入新账号记录或发起后续请求。

这项变更不清空当前用户在账号命名空间内的历史。再次登录同一账号仍可恢复该账号自己的本地会话；服务端授权继续由原有认证接口负责。
