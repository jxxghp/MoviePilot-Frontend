# 消息渠道前端任务清单

导航：[设计](design.md) · [计划](plan.md) · [验证](validation.md)

| 任务                   | 交付                                                     | 状态             |
| ---------------------- | -------------------------------------------------------- | ---------------- |
| 配置导航               | 消息 & 交互入口、单组消息渠道卡片，无嵌套标签页。        | 已实现           |
| 卡片生命周期           | 新建、显式保存、拖拽、更多菜单及完整删除。               | 已实现           |
| 三页管理               | 连接、通知、交互独立草稿和版本，图标切换。               | 已实现           |
| 首次使用规则           | 四种策略、开放提示、允许操作、平台条件及群组命名。       | 已实现           |
| 自动下载规则           | 按连接关闭、规则、全部，移除全局表单。                   | 已实现           |
| 投递规则               | 规则名字、时间、组合通知类别和无操作用户策略。           | 已实现           |
| 规则组件               | 卡片开关、编辑与删除、导入/清空/分享、过滤及副标题计数。 | 已实现           |
| 渠道授权               | 单条及批量操作、权限范围、已授权删除二次确认。           | 已实现           |
| 设备与会话             | Web Push 切号隔离、迟到操作保护及账号关联入口。          | 已实现           |
| 提交前检查             | 当前源码的自动化及真实浏览器结果。                       | 见验证文档       |
| 真实企业微信及生产部署 | 离线组件及浏览器验收不等于平台验收。                     | 部署前按环境执行 |

授权、迁移与业务归属的任务状态由[后端任务清单](https://github.com/jxxghp/MoviePilot/blob/v3/docs/channel-refactor/tasks.md)维护。
