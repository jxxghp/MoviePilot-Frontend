# 消息渠道前端实施计划

导航：[设计](design.md) · [任务](tasks.md) · [验证](validation.md)

| 顺序 | 交付物             | 验收要求                                                    |
| ---- | ------------------ | ----------------------------------------------------------- |
| 1    | 能力与资源接口     | 三种资源和 revision，支持类型与目标来自能力目录。           |
| 2    | 单组连接卡片       | 新建、保存、排序、更多菜单和删除保持配置页风格。            |
| 3    | 三页管理与草稿     | 默认连接配置，图标切换，无嵌套标签，显式保存。              |
| 4    | 统一规则弹窗       | 卡片、开关、独立编辑、导入/清空/分享和能力过滤。            |
| 5    | 授权及账号生命周期 | 批量审批、删除确认、关联码及 Web Push 切号隔离。            |
| 6    | 配套验证           | 全量组件测试、格式、lint、类型、生产构建和桌面/移动浏览器。 |

前端与配套后端共同部署，不能仅凭旧接口存在就回退到旧表单。部署前备份后端数据库与配置，升级及回退步骤见[后端计划](https://github.com/jxxghp/MoviePilot/blob/v3/docs/channel-refactor/plan.md)。生产发布及真实平台验收单独安排。
