# 消息渠道前端实施计划

导航：[设计](design.md) · [任务](tasks.md) · [验证](validation.md)

| 顺序 | 交付物             | 验收要求                                                    |
| ---- | ------------------ | ----------------------------------------------------------- |
| 1    | 能力与资源接口     | 三种资源和 revision，支持类型与目标来自能力目录。           |
| 2    | 单组连接卡片       | 新建、保存、排序、更多菜单和删除保持配置页风格。            |
| 3    | 三页管理与草稿     | 默认连接配置，图标切换，无嵌套标签，显式保存。              |
| 4    | 统一规则弹窗       | 卡片、开关、独立编辑、导入/清空/分享和能力过滤。            |
| 5    | 授权及账号生命周期 | 批量审批、删除确认、关联码及 Web Push 切号隔离。            |
| 6    | 配套验证           | 全量组件测试、格式、lint、类型、生产构建和桌面/移动浏览器。 |

前端与配套后端共同部署，不能仅凭旧接口存在就回退到旧表单。部署前备份后端数据库与配置，升级及回退步骤见[后端计划](https://github.com/jxxghp/MoviePilot/blob/v3/docs/channel-refactor/plan.md)。生产发布及真实平台验收单独安排。

## 通用核心与平台表单分离

公共设置页消费 `GET notification/channels` 的 `providers` 和按连接 ID 的 `capabilities`，不维护内置类型清单，不按平台名推导规则类型、线程、账号筛选、凭据或登录管理。平台值仍保留在分享格式内，用于阻止跨类型导入。

连接表单继续复用既有平台配置页。专属交互配置通过 `ChannelInteractionExtension` 使用 Vite 已有组件发现机制加载 `forms/<extension>.vue`；Discord 命令服务器表单读写 `platform_options`。未知扩展不渲染平台字段，保存时保留原选项，由后端模块执行实际校验。增加平台表单无需改共享设置页、规则弹窗或核心授权代码。

规则弹窗按能力显示线程及标签；不解释平台 ID 正则。新增合成渠道测试使用非数字线程，证明新平台能力只需后端描述；公开 API 的兼容由后端维持。能力描述不代表当前用户获准操作，最终审批、业务范围、连接/群组/线程隔离与凭据校验由后端执行。

本轮顺序：配套后端能力契约 → 共享页消费 → 平台专属表单 → 扩展/架构组件回归 → format/lint/type/full tests/build → 桌面和移动浏览器。本轮只交付本地审阅，不发布或切换手测实例。
