# 社区勋章渲染图

本目录的文件由 `src/utils/communityMedalArt.ts` 按文件名自动收录，放入即生效，缺失时页面退回绘制的六边形后备。

| 文件                                                    | 用途                                                                                                   |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `<key>-front.webp`                                      | 独枚勋章的正面                                                                                         |
| `<key>-front-t1.webp` 至 `<key>-front-t4.webp`          | 阶梯勋章（`code`、`plugin`）每档一张正面，同一外形、做工逐档更丰富，档位由图本身表达                   |
| `<key>-back.webp`                                       | 背面，所有档位共用一张，抛光背板上一块下沉的空铭牌，勋章名、等级、授予对象、时间与制造者印记由页面刻上 |
| `<key>-badge.webp`、`<key>-badge-t1.webp` 至 `-t4.webp` | 顶栏佩戴标识，与正面同档，96×96、按不透明区域裁切居中后预先缩小，页面以 32 CSS 像素显示                |
| 每张面图同名加 `-height.webp`                           | 与渲染图逐像素对齐的高度图，如 `code-front-t2-height.webp`、`code-back-height.webp`，精绘视差与补光用  |
| 每张面图同名的 `.outline.json`                          | 外轮廓与浮在本体外的宝石圆（镶嵌的宝石为 `null`），背面轮廓另含铭牌 `dial`，精绘挤出侧壁与定位刻字用   |

`<key>` 是贡献类型，与显示名解耦：`code` 编剧、`plugin` 布景、`maintainer` 主创、`helper` 掌灯、`security` 守夜、`tester` 试映、`pioneer` 启幕。高度图与轮廓由 `design/community-medals/` 的 `build_maps.py` 从原图算出。

## 缺图时的回退

- 阶梯勋章缺本档正面时取最近的较低档，没有任何不高于本档的正面或缺背面时，退回页面绘制的六边形。
- 只有正反面图、缺本面的高度图或轮廓时，精绘退回倾斜双图卡片。
- 顶栏佩戴标识与保存图片都使用这条规则选出的本档正面（佩戴标识取对应的 badge 小图，缺图时显示线框勋章图标）。

## 外圈转动

正面轮廓可带 `spin`，目前只有主创（`maintainer-front.outline.json`）带。

| 字段               | 含义                                                                                                    |
| ------------------ | ------------------------------------------------------------------------------------------------------- |
| `x`、`y`、`r`      | 圆心与内半径，按整张图的比例；半径以外的外圈整体转动，出图时要在 `r` 处留一道深色缝遮住接缝             |
| `mode`             | `tick` 走格（缺省）或 `continuous` 匀速                                                                 |
| `step`、`interval` | 走格模式每格的角度（度，缺省 6）与两格之间的秒数（缺省 2）；每一步约 350 毫秒缓入缓出，带约 0.4° 的回弹 |
| `period`           | 匀速模式转一圈的秒数                                                                                    |

光泽按固定的世界光源计算，不跟着外圈走；渲染图里原有的高光会随外圈转动，走格让它读起来像机械表的擒纵。系统减少动态效果、页面隐藏或画布不在视口时不转，顶栏佩戴标识、倾斜卡片与保存图片都是静止的。

调试覆盖：在浏览器本地存储里把 `community-medal-spin-mode` 设为 `continuous` 或 `tick`（或在网址查询串加 `medal-spin=continuous`），重新打开展台即按该模式转动，便于对比；不设置时按轮廓数据。这只影响当前浏览器，对线上没有副作用。

## 刻字区

刻字区取背面轮廓里的 `dial`（`x`、`y` 为铭牌中心，`width`、`height` 为铭牌宽高，都按整张图的比例），由 `build_maps.py` 量出。量得不准时在 `communityMedalArt.ts` 的 `MEDAL_ART_META` 登记 `dial` 覆盖，也可用 `ink` 覆盖凹槽颜色；都没有时取默认区域。

刻字的版式所有勋章一致：勋章名、等级与称号（阶梯勋章）、授予对象、时间，最后一行是开放六边形加 MoviePilot 的制造者印记。凹槽颜色由铭牌处金属的实际颜色推出。精绘里刻字是背面上单独的一层，按屏幕分辨率直接画；任何一行都不小于 10 CSS 像素，铭牌放不下时先省略时间行，再省略授予对象（两者在展台与详情里都有），名字与印记始终保留。

## 显示尺寸

精绘按设备像素比渲染（最高 3 倍），贴图在运行时从 1200 的原图高质量缩到勋章在屏幕上实际占的像素，再按外形包围框取景并留出约 8% 与偏转余量，因此展台不需要另备多套尺寸的 WebP。顶栏只有 32 像素，浏览器从 1200 像素缩小会发糊，所以单独预备 badge 小图。
